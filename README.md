# NoteHub — Authentication & Protected Routes

This project is a Next.js application that implements authentication, protected routes, and integration with a provided backend API.  
The backend logic was supplied as part of the assignment, since backend development has not yet been covered in the course.

## 🚀 Features

- User authentication (Sign in / Sign up / Logout)
- Session handling with access & refresh tokens
- Protected routes for authorized users
- Public routes for authentication pages
- Client-side and server-side API separation
- Notes management (list, details, filtering)
- Conditional navigation based on authentication state

## 🛠 Tech Stack

- **Next.js 16 (App Router)**
- **TypeScript**
- **Axios**
- **@tanstack/react-query**
- **CSS Modules**
